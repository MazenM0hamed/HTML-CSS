# 📝 My Learning Journal

A responsive personal blog website created to document my learning journey as a developer. This project focuses on building a clean, flexible, and user-friendly experience across different screen sizes.

The main goal of this project was to practice **responsive web design**, improve my understanding of **CSS Grid and Flexbox**, and create a layout that adapts smoothly between desktop, tablet, and mobile devices.

---

## 🚀 Overview

My Learning Journal is a multi-page blog-style website that includes:

- A navigation bar
- A hero section
- Blog post cards
- An About Me section
- A footer section

The project was designed with flexibility in mind, making sure that content remains readable and well-structured regardless of the device being used.

---

## ✨ Features

- Fully responsive layout
- Mobile-friendly design
- Flexible navigation system
- Hero section with responsive background image
- Blog cards displayed using CSS Grid
- Adaptive layouts using media queries
- Responsive typography
- Clean and organized structure
- Hover effects for better user interaction

---

# 📱 Responsive Design

One of the main focuses of this project was creating a website that works well on different screen sizes.

## Desktop Design

On larger screens:

- Blog posts are displayed in a 3-column grid layout
- Navigation links are arranged horizontally
- Content uses available space efficiently
- Images automatically adjust to their containers

## Mobile Design

For smaller screens:

- Blog cards change into a single-column layout
- Navigation spacing is adjusted
- Text sizes are optimized for readability
- Sections stack vertically
- Images scale according to screen width

The design uses CSS media queries to provide a smooth transition between different screen sizes.

# NFT Landing Page

A responsive NFT landing page built with **HTML5** and **CSS3**. This project focuses on creating a mobile-first layout using **CSS Media Queries** and **Flexbox** to provide a seamless experience across different screen sizes.

---
## 🚀 Features

- Mobile-first responsive design
- CSS Flexbox layouts
- Responsive navigation
- Flexible image sizing
- Media queries for tablet and desktop screens
- Reusable button components
- Clean semantic HTML structure
- Google Fonts integration

---

## 📱 Responsive Design

The website is built using a **mobile-first approach**.

### Mobile Layout (< 768px)

- Navigation links stack vertically.
- Header content is centered.
- Buttons take the full available width.
- Images scale to fit the screen.
- Feature cards wrap naturally for smaller displays.

### Desktop Layout (≥ 768px)

Media queries transform the layout into a desktop-friendly design by:

- Displaying the header content with Flexbox.
- Positioning the navigation horizontally.
- Increasing section spacing.
- Enlarging typography for better readability.
- Displaying buttons inline.
- Improving overall page spacing and alignment.

# WeBarelyWork – Coworking Spaces UI

A simple responsive landing page showcasing coworking spaces for developers. This project focuses on modern CSS techniques like Flexbox, positioning, and UI layout styling.

## Preview

The website includes:
- Navigation bar with logo and icons
- Hero section heading
- Card-style coworking space listings
- Image banners (e.g., "Exclusive")
- Fixed chat button (floating action button style)

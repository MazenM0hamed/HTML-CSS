# 📌 Project Overview
The Hometown Homepage highlights a fictional travel destination (Torshov, Oslo) and presents:

- A visually appealing hero section with background image and title  
- A top activities section displaying popular things to do  
- A guide section introducing a local guide  

The goal of this project is to practice front-end fundamentals and build a structured, visually balanced webpage.

# 🎯 Features

- Responsive layout using Flexbox  
- Clean section-based design  
- Centered content and consistent spacing  
- Styled cards for activities  
- Profile-style guide section  
- Custom color palette
